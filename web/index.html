This is the root of the frontend container. The review, preview and send screens described in docs/design are not built yet — this page exists so that the origin they will be served from can be checked from a browser.

What this origin is doing

    The API is reached only through /api on this origin, and holds the Amplify credential on a network this container is not on. The browser holds no credential of any kind: this service attaches its own to everything it forwards, which is why the version check succeeds without the page ever having seen one.
